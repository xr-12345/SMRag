# Phase 2B 筛选 Go / No-Go 判定

**判定：No-Go —— joint_gate 不进入 N=20。**

基线 = `rank_only_w0.0`。逐条判据以**最优冻结候选 `joint_gate_w1.0`** 为准（w0.1 / w0.5 因
0.3 噪声下 Top-1 超限出局，不作为冻结候选）。

## 判读

- **机制成立**：joint_gate 精准触发真实误报核验（60–74% 真命中），门打开从不强制核验
  （13–28 例门开但 AskNew 效用更高），符合 Phase 2A 设计。
- **效率改善但诊断持平**：不必要核验率下降、冲突解决率上升是稳定的正向信号；但 Top-1 完全持平，
  Brier 改善幅度小且无 Top-1 佐证，不构成「明确诊断风险下降」。
- **统计功效**：N=245 下 Top-1 二项标准误 ≈ 2.6 pp，所有配置 Δ 均 < 1.3 pp（< 0.5 σ），
  即 N=5 已能排除「≥ 1 pp 的诊断增益」。
- **科学解释**：joint_gate 找得到错（60–74% 真命中），但纠正这些错不改变最终诊断——后验对这些
  具体误报稳健，故「找错」未转化为「诊对」。

## 最终决定

（82,320 轮、12 进程 ~4.7 h）去确认一个 N=5 已显示「无诊断增益」的假设，期望价值低。
