# 可识别性限制 (IDENTIFIABILITY_LIMITATIONS)

本文件记录「复问相关性对齐」这一实验能证明什么、不能证明什么，避免把合成相关性
描述成临床真实（红线 #11）。

## 1. 模型能观测到什么

推断模型（`JointReliabilityBeliefTracker` + `JointReportChannel`）在每个对话里
只能观测到**回答序列** `(Y_i, Y_i')` 及其确定性线索 `certainty`。它观测不到：

- 真实临床状态 `Z_i`（latent）；
- 真实报告模式 `E_i`（隐藏，本实验为评估侧才记录）；
- 环境相关性 `rho_env`（模拟器隐藏参数）；
- 真实疾病 `D`（推断目标）。

因此模型对「第二次回答是否与第一次回答相关」的信念，只能来自它对
`rho_model` 的**先验假设**（`repeat_mode_persistence`），无法从单条回答序列中
直接读出 `rho_env`。

## 2. 相关性 ρ 的不可识别性

`rho_env` 与 `rho_model` 都进入联合分布 `P(Y, Y' | z)` 的形状。从**一条**复问
对话里，回答对 `(Y, Y')` 的联合统计量原则上能对 `rho` 提供信息，但：

- 单个病人、单个 feature 的两次回答，样本量为 1，无法估计 `rho`；
- 需要**跨病人、跨 feature 的大样本**才能区分 `rho=0` 与 `rho=0.9` 的联合分布；
- 本实验在 N=5 验证集（245 case）上只做**评估**，不从这些数据拟合 `rho`
  （红线 #6、#8、#7）。

结论：**对齐是可评估的，但不是可学习的部署参数**。本实验回答的是「当假设正确
（对齐）时模型是否正确」与「当假设错配时代价多大」，而不是「如何从数据估计
rho」。

## 3. 合成相关性 ≠ 临床真实（红线 #11）

`rho_env` 是一个**合成的**复问相关机制，其 `T_v(e'|e) = rho*1[e'=e] + (1-rho)*P(e')`
形式是为了让模拟器与 `JointReportChannel` 共享同一联合模型、从而可做频率对齐
验证而设计的。它**不代表**临床复问相关性的真实结构：

- 真实临床中，复问的模式相关性可能随 feature 类型、病人、时间、提问方式变化；
- 本实验的 `rho_env` 是全局常数（对每个 feature 相同），是一种理想化；
- `repeat_mode_persistence` 是推断模型的建模假设，不是临床测量的参数。

因此本实验的结论只能表述为「在共享联合模型的合成环境下，推断与环境的对齐/错配
如何影响诊断」，不得推广为「临床复问相关性是 ρ=0.5」等事实性论断。

## 4. 对 GO/NO-GO 的影响

- GO/NO-GO 不依据「哪个 `rho_model` 在 N=5 上 Top-1 最高」来选择部署参数（红线
  #7）；而是依据「机制是否成立（对齐时行为正确、错配时代价可度量）」与「联合
  通道策略相对基线是否有诊断增益」。
- 若 N=5 显示对齐敏感性（即 `rho_model` 的设定显著影响诊断），则结论是「部署
  前必须确定真实的复问相关性」，而非「用 N=5 拟合一个 rho」。
